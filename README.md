# Hello
This project uses the Next.js App Router; the home page is the Reading Room.

## 1. Pages
The home page is `app/page.tsx`, and its UI lives in `components/ReadingRoom.tsx`.

## 2. run & build
```
npm start
npm run build
```

## 3. deploy
After `npm run build`, upload the files in `out/` to the site root.
